# ollama部署

## 一. docker-compose启动
```yaml
version: '3'

services:
  ollama:
    image: ollama/ollama
    container_name: ollama
    ports:
      - '11434:11434'
    volumes:
      - ./data:/root/.ollama
    restart: always
    networks:
      - docker
networks:
  docker:
    external: true
```

## 二. 按照大模型

可安装大模型列表
https://ollama.com/library

可根据CPU与内存选择相应的模型

```shell
docker exec -it ollama ollama run llama3.1
```
